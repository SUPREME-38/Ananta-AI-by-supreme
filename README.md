## ✨ Features & Capabilities

Ananta intelligently routes user intent across five specialized modules, ensuring accurate, hallucination-free responses backed by **authentic research and resources**.

* 🛍️ **Shopping Assistance** – Visual product search, spec comparisons, and smart recommendations.
* 🎮 **Gaming Guidance** – Lore, walkthroughs, strategies, and screenshot analysis.
* 💬 **Conversational AI** – High-fluidity chat for brainstorming and daily queries.
* 📈 **Productivity & Skills** – Curated roadmaps for skill unlocking and execution.
* 🛠️ **FIXO** – Real-time technical troubleshooting and hardware diagnostics.

> 📊 **Authentic Intelligence:** Ratings and recommendations are driven by verified metrics and authentic customer reviews. No fluff.

## 🏗️ Architecture 

Designed with high security, privacy, and speed at the forefront:

* **Frontend:** React.js + Tailwind CSS (Zero clutter, chat-first UI)
* **Backend & Security:** Supabase (Secure authentication & database architecture)
* **Hosting:** Vercel (Edge-optimized performance)
